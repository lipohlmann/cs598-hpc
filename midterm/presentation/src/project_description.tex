\begin{frame}{Toy Problem}
  For this implementation, we look to solve the following toy problem:

  Find $\tilde{u}\in \mathcal{R}^3$ s.t.
  \begin{equation}
    \label{eq:poisson}
    -\nabla^2 \tilde{u}=f(x,y,z),\quad \tilde{u}\in \Omega,\quad u\in\partial \Omega=0.
  \end{equation}
  for $x,y,z\in [0,1]^3$.
\end{frame}
